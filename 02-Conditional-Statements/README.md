# Python Conditional Statements

This folder contains Python programs based on conditional statements
and decision-making.

## Topics Covered

- if statement
- if-else statement
- if-elif-else statement
- Nested if statements
- Conditional expressions

## Practice Questions

1. Write a program to check whether a number is positive, negative, or zero.
2. Write a program to check whether a number is even or odd.
3. Write a program to find the largest of two numbers.
4. Write a program to find the largest of three numbers.
5. Write a program to check whether a person is eligible to vote.
6. Write a program to check whether a year is a leap year.
7. Write a program to assign grades based on marks.
8. Write a program to check whether a character is a vowel or consonant.

## Objective

- Understand decision-making in Python.
- Learn how to use conditional statements.
- Apply conditions to solve programming problems.
- Improve logical thinking and problem-solving skills.
