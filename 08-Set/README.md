## Sets

This folder contains my Python programs and practice based on Sets.

## Topics Covered

- Creating and accessing sets
- Adding and removing elements
- Set methods
- Set operations
- Union and intersection
- Difference and symmetric difference
- Checking membership
- Removing duplicate elements

## Programs

- Create and print a set
- Add elements using "add()"
- Add multiple elements using "update()"
- Remove elements using "remove()" and "discard()"
- Find the length of a set
- Check whether an element exists in a set
- Perform union of two sets
- Find intersection of two sets
- Find difference between two sets
- Find symmetric difference
- Remove duplicates from a list using a set
- Check subset and superset relationships

Learned how to create and manipulate sets in Python and understood their unique elements, unordered nature, and set operations.
